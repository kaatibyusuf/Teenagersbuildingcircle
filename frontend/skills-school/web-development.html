Overview

From a blank file to a live website. You learn the front end, the back end and how to put a real product online.

The track runs for eighteen months in three phases of six months: Foundations, Practice and Ship. You learn live with your teacher, build real projects as you go, and finish with a final project and a portfolio.

Who this is for

Beginners who want to build websites and web apps
Students who want a practical skill and a portfolio
Business owners who want to build their own site

What you will learn to do

Build responsive websites with HTML, CSS and JavaScript
Create web apps with a database and user accounts
Use Git and GitHub like a working developer
Deploy your work so anyone can open it

Curriculum

Months 1 to 6Foundations
  • HTML, CSS and responsive layout
  • JavaScript from the ground up
  • Git and GitHub
Months 7 to 12Practice
  • A front-end framework such as React
  • Servers, APIs and databases
  • Accounts, forms and security basics
Months 13 to 18Ship
  • Plan, build and test a full web app
  • Deploy and maintain it
  • Portfolio site and code review

Tools you will meet

HTML and CSSJavaScriptReactNode.jsGitVercel

Your final project

Design, build and launch a complete web app that real people can use.

What is included

Live online classes

Times that suit you

Your own student portal

Real projects
Every phase ends with work you can show.

Frequently asked questions

Who can join?

Anyone who wants to learn a skill properly. This track starts from the basics, so a complete beginner can begin on day one.

What do I need to take part?

A laptop or computer and a steady internet connection.

How are classes held?

Classes are live online. There is no fixed timetable. After you enrol, your teacher agrees the days and hour with you, around school, work and family.

How long is the track?

Eighteen months, in three phases of six months: Foundations, Practice and Ship.

Can I change my track after I pay?

Plans cannot be changed after the registration fee is paid. A change means a fresh registration, so choose carefully. The track matcher on the Skills Schools page can help you decide.

How much does it cost?

The track costs ₦200,000 for the full eighteen months. A one-time registration fee of ₦3,000 is added to your first payment.

Where do I ask a question?

Message us on WhatsApp on +234 704 722 6487, or use the contact page.
